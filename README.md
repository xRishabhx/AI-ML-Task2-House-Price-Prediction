## 📌 Project Overview

This project was developed as part of an **Artificial Intelligence & Machine Learning Internship – Task 2**.

The objective of this project is to build an enhanced **House Price Prediction System** using Machine Learning techniques and compare the performance of multiple regression algorithms.

The project demonstrates a complete Machine Learning workflow including:
- Data preprocessing
- Feature scaling
- Model training
- Performance evaluation
- Model comparison
- Best model selection

---

# 📂 Dataset Used

The project uses the **California Housing Dataset** from `scikit-learn`.

### Features Included:
- Median Income
- House Age
- Average Rooms
- Average Bedrooms
- Population
- Latitude
- Longitude

### Target Variable:
- Median House Value

# 🔍 Machine Learning Workflow

## 1️⃣ Data Loading
- Loaded California Housing Dataset
- Converted dataset into pandas DataFrame

## 2️⃣ Data Exploration
- Dataset analysis
- Statistical summary
- Missing value checking

## 3️⃣ Data Visualization
- Correlation heatmap
- Model comparison graph

## 4️⃣ Feature Scaling
Applied:
- `StandardScaler`

to standardize feature values before model training.

## 5️⃣ Train-Test Split
Dataset divided into:
- 80% Training Data
- 20% Testing Data

## 6️⃣ Model Training
The following regression models were trained:
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## 7️⃣ Model Evaluation
Models were evaluated using:
- MAE (Mean Absolute Error)
- MSE (Mean Squared Error)
- RMSE (Root Mean Squared Error)
- R² Score
